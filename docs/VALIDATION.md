# 1.0.0 검증 기록

2026-10-13에 개발용 격리 환경에서 수행했다. 운영 서버, 운영 API와 운영 DB는
변경하지 않았다. 아래 결과는 이 저장소의 최초 1.0.0 구현에 대한 기록이다.

## 환경

- Minecraft 1.20.4, Fabric Loader 0.18.4, Fabric API 0.97.3+1.20.4
- 게임 서버: Eclipse Temurin Java 17
- 빌드: Java 21, Gradle 8.12.1, Fabric Loom 1.10.5, Java 17 대상 바이트코드
- API: `minefed-api` 커밋 `ad407eb6df88ded90f2478db9371ce58b5e4d4e7`
- 데이터베이스: 로컬 격리 PostgreSQL 16
- 실제 실행 대상: `build/libs/minefed-regions-1.0.0.jar`의 remapped 배포 JAR

검증한 JAR의 SHA-256:
`3477e2c1e934edf5cfb1838d6906bf1ade516f1c8c742fed387e81bfc5f5858c`

## 자동 검사

`gradlew test remapJar`가 성공했다. JUnit **26개 모두 통과, 건너뜀 0개**다.

- 계층 주소, 동일 경계선에서 일관된 소속 선택, 조상 권한과 자기 지역 편집 금지
- snapshot 구조·크기·좌표·계층·문자열 검증과 외부 변경으로부터의 방어적 복사
- 경계 작업본의 외곽·구멍·분리 영역, 정점 변경과 오래된 기준 버전
- 실제 명령 실행자 식별과 실행 대상 플레이어를 바꾸는 명령의 사칭 방지
- 서버 연결 설정, 제한된 HTTP 응답 크기와 전송 처리
- 실제 Java 클라이언트 → Go API → PostgreSQL 왕복: 관리자 등록, 생성·이름 변경,
  권한 없는 수정 거부, 요청 중복 적용 방지, 이력 커서 조회와 테스트 데이터 정리
- BlueMap 마커 데이터, 좌표, 전체 주소와 안전한 HTML 출력

실제 API 통합 검사는 `MINEFED_REGIONS_TEST_CONFIG`가 가리키는 로컬 설정 파일을
사용한다. 이 변수가 없는 일반 빌드에서는 해당 통합 검사 하나를 건너뛴다.
토큰을 포함한 설정 파일은 소스나 테스트 보고서에 커밋하지 않는다.

`node --test src/test/js/regions-map.test.cjs`의 **6개 검사도 모두 통과**했다.
줌에 따른 표시 단계, 서로 다른 깊이의 계통, 잎 지역 유지, 레이어 토글과 다른
마커 레이어 보존을 검사했다.

관련 API 저장소에서는 전체 Go 테스트와 vet, PostgreSQL 통합 및 race 검사,
실제 HTTP 프로세스 검증을 별도로 통과했다. 이력 105개를 이동하며 조회 중 추가
변경이 발생해도 페이지 간 중복·누락이 없는지 확인했다.

## 실제 Minecraft 서버

운영 서버와 다른 폴더·월드·loopback 포트에서 Java 17로 배포 JAR를 실행했다.
BlueMap 없이 다음을 확인했다.

- Fabric 초기화와 명령 실행자 접근용 Mixin 로딩, API 온라인 상태
- 큰 페이지 번호 입력 시 서버가 계속 실행되며 유효한 오류 응답
- 서버 콘솔의 관리자 등록, 지역 이름 변경 → 이력 조회 → 되돌리기
- 이름을 `Server`로 바꾼 명령 블록이 콘솔 권한을 얻지 못하며 API 데이터도 불변
- API 프록시를 실제로 중단했을 때 마지막 정보를 유지하고 수정 요청을 차단
- 캐시에 서버 토큰이 포함되지 않음
- API가 중단된 상태로 서버를 다시 시작해 캐시 복원과 읽기 전용 상태 확인
- 검증 서버의 정상 종료

## 실제 BlueMap 연동

같은 배포 JAR와 BlueMap `5.3-minefed.2`를 함께 설치한 별도 테스트 서버에서
BlueMap 활성화와 일반 월드 연결을 확인했다. loopback HTTP 서버로 다음 데이터를
직접 읽어 검증했다.

- `settings.json`에 행정구역 전용 JavaScript와 CSS 등록
- `minefed-regions` 마커 레이어 생성과 자산 HTTP 응답
- 국가 본토·분리된 섬·하위 도시의 경계 3개와 이름 마커 3개
- 내부 구멍 1개, 투명한 면과 표시되는 윤곽선
- 클릭 정보의 전체 주소와 HTML 이스케이프
- 실제 API 이름 변경이 마커에 반영되고, 도시 삭제 후 마커가 6개에서 4개로 감소
- 테스트 서버 정상 종료와 테스트용 게임·웹·API 프록시 포트의 listener 종료

실제 Minecraft 검사 11개와 BlueMap 검사 5개가 모두 통과했다.

## 확인 범위

클라이언트 HUD의 실제 게임 화면과 BlueMap 브라우저의 육안 렌더링 검사는 수행하지
않았다. 자동 계산·데이터·서버 연동 검사와 구분한다. 운영 적용 시에는 설치 환경에서
선택 도구를 사용하고 경계에 진입해 HUD를 확인하며, BlueMap의 2D·3D 확대 및
지역 클릭을 확인해야 한다. 운영 배포와 운영 DB 마이그레이션은 별도 작업이다.
